# SIFT OCR — Распознавание текста с изображения / скриншота

Простое десктопное приложение на Python для распознавания текста с помощью **SIFT** (OpenCV).  
Поддерживает русский и английский языки + проверку орфографии.

## Возможности
- Захват части экрана или загрузка изображения из файла
- Автоматическое выделение букв
- Распознавание с помощью SIFT-дескрипторов
- Проверка и исправление орфографии (LanguageTool)
- Вывод текста в буфер обмена или в .txt

## Требования к системе

- **Python 3.9+**
- **Java 17 или выше** ← ОБЯЗАТЕЛЬНО! (для работы spellcheck)
- Windows / Linux / macOS
